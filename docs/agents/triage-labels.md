# Triage Labels

工程技能使用五个标准 triage 角色。本文件把这些角色映射到本仓库实际使用的状态字符串。

| 技能角色 | 本仓库状态 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息足够完整，可以交给 agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人类实现或决策 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个 triage 角色时，使用上表中的“本仓库状态”字符串。
