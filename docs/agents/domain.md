# Domain Docs

本文件说明工程技能如何读取本仓库的领域文档。

## 阅读顺序

开始探索代码前，优先读取：

- 根目录 `CONTEXT.md`：项目领域语言、核心概念、边界和常用术语
- 根目录 `CONTEXT-MAP.md`：如果存在，表示多上下文项目，并会指向各上下文的 `CONTEXT.md`
- `docs/adr/`：与当前工作相关的架构决策记录

如果这些文件不存在，静默继续。不要因为缺少它们而中断任务；`grill-with-docs` 等技能会在需要沉淀术语或决策时再创建它们。

## 当前布局

本仓库采用 single-context 布局：

```text
/
├─ CONTEXT.md
├─ docs/
│  └─ adr/
└─ Source/
```

## 使用领域词汇

当输出 issue 标题、重构建议、诊断假设、测试名或实现说明时，优先使用 `CONTEXT.md` 中定义的术语。不要随意换同义词。

如果需要的概念尚未记录，说明可能存在术语缺口；可以在结论中提醒后续用 `grill-with-docs` 补充。

## 识别 ADR 冲突

如果建议或改动与已有 ADR 冲突，需要明确指出，而不是静默覆盖。
